Analysis Pipeline

01

Knowledge Base Ingestion

security.json, bad_practice.json, performance.json are embedded and stored in Chroma vector DB.

02

Retrieval Node

Target source code is embedded and matched against known vulnerability patterns via similarity search.

03

Analysis Node

LLM (via LangGraph) receives the retrieved patterns and generates a structured audit report with RULE_IDs.

04

Scoring Node

Code is rated on Performance, Bad Practices, and Security on a 1–10 scale for visualisation.
